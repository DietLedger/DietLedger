# GitHub beta release materials — draft

## Objective and user value
Prepare an accurate, compelling public-facing beta launch for DietLedger. Help prospective users understand the integrated nutrition workflow, evaluate self-hosting and licensing, and reach the GitHub repository.

## Approved scope and acceptance criteria
- Supply a cohesive set of account/repository identity assets based on the existing DietLedger brand, including appropriately sized profile images and a repository social preview, with reusable source where practical.
- Provide a concise GitHub repository description and an installation-oriented README that identifies prerequisites, actual tested setup steps, configuration/security considerations, beta status, and links to the full source-available Community Care License. Do not claim all uses are free or call the project open source.
- Create a responsive, accessible static GitHub Pages landing page with a prominent repository call to action. Emphasize verifiable nutrition and dietary filtering, meal planning, grocery lists, and self-hosted ownership without medical promises, invented endorsements, or unsupported conversion claims. Use relative asset links suitable for a repository Pages path.
- Document any required GitHub-side configuration; do not publish, change GitHub settings, rotate secrets, or alter the license without explicit authorization.

## Approved assumptions and release blockers
- Target repository: https://github.com/DietLedger/DietLedger; GitHub Pages repository site.
- Use existing DietLedger logo and branding; speak to households and care professionals equally.
- Retain the current Community Care License 1.0 unchanged. State that the user has identified this release as beta; do not imply a public hosted instance or published release artifact exists.
- `.env` is tracked and includes populated password, HMAC secret, and API key fields. Review exposure and Git history before publication; rotate any real secrets and remove sensitive history using an approved process. This release-materials task does not authorize those operations.
