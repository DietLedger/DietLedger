# docs/documentation_inventory.md

Status: Living Documentation Inventory

Purpose:

This document tracks the status, completeness, ownership, review history, and source validation state of every document within the DietLedger documentation system.

This file is intended to serve as the primary documentation management artifact for maintainers and AI-assisted development agents.

---

# Status Definitions

| Status        | Meaning                                                  |
| ------------- | -------------------------------------------------------- |
| Planned       | Document has not yet been created                        |
| Draft         | Initial version exists but is incomplete                 |
| Review Needed | Requires technical review                                |
| Verified      | Verified against source code and authoritative documents |
| Current       | Verified and believed current                            |
| Deprecated    | No longer authoritative                                  |
| Archived      | Historical reference only                                |
